# data

측정 데이터 폴더입니다. 형식은 [ESP32 로거](../arduino/ALIGN_logger/ALIGN_logger.ino)와 [CSV 수집기](../python/data_logger/collect_csv.py)가 실제로 저장하는 형식을 따릅니다. 이 형식에서 벗어난 CSV는 학습 스크립트(`train_model.py`)가 거부합니다.

## 세션 하나 = 파일 3개

`collect_csv.py`를 한 번 실행하면 한 세션이 기록되고, 같은 이름으로 파일 3개가 생깁니다.

```
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.csv            센서 값
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.summary.json   수집 품질 요약
<피험자>_<YYYYMMDD>_<HHMMSS>_<8자리 hex>_label<0|1>.events.txt     로거 메시지·오류 기록
예: P01_20261113_152557_db3c0163_label1.csv
```

- **피험자**: 실명 대신 `P01`, `P02`, `P03` 같은 코드(영문·숫자·`_`·`-`, 40자 이내)를 씁니다. 저장소가 Public입니다.
- **세션 ID**: `<날짜>_<시각>_<랜덤 8자리>`로 자동 생성됩니다. 세션 하나는 한 라벨만 가집니다.
- 파일은 덮어쓰지 않고 항상 새로 만듭니다.

## CSV 열 (17개)

| 열 | 단위 | 설명 |
| --- | --- | --- |
| `session_id` | - | 세션 ID (파일 안에서 모두 같음) |
| `subject_id` | - | 피험자 코드 |
| `label` | - | `0` 또는 `1` (아래 라벨 참고) |
| `seq` | - | 수집 시작(`S` 명령) 후 20ms 슬롯 번호. 건너뛴 슬롯도 번호를 쓰므로 번호가 비면 누락 |
| `time_us` | µs | ESP32 부팅 후 시간(`esp_timer`), 두 센서를 읽기 시작한 시각 |
| `imu1_ax_g`, `imu1_ay_g`, `imu1_az_g` | g | IMU 1(0x68, 흉추) 가속도. **중력 포함** |
| `imu1_gx_dps`, `imu1_gy_dps`, `imu1_gz_dps` | °/s | IMU 1 각속도 |
| `imu2_ax_g` … `imu2_gz_dps` | g, °/s | IMU 2(0x69, 요추), 순서는 IMU 1과 같음 |

각도(상대 각도 등)는 CSV에 저장하지 않고, 분석·학습 단계에서 원시값으로 계산합니다.

## 센서 설정

| 항목 | 값 |
| --- | --- |
| 샘플링 | 50Hz (내부 1kHz ÷ 20) |
| 저역통과 필터 | DLPF 3 (약 44Hz) |
| 범위 | 가속도 ±2g, 자이로 ±250°/s |
| I2C | 400kHz, SDA 21 / SCL 22 |
| 시리얼 | 115200 baud, PC에서 `S` 보내면 시작 / `X` 보내면 중지 |

## 라벨

| 값 | 의미 |
| --- | --- |
| `0` | 바른(정상) 자세 |
| `1` | 불량 자세 |

로거는 세션 하나에 0/1 하나만 붙입니다. 바른 자세 10초, 구부정 10초처럼 **자세를 하나만 유지하는 세션**에는 이것으로 충분합니다.

### 구간 라벨 파일 (3차 실습용 제안)

3차 실습처럼 한 세션 안에 여러 자세와 일시 동작이 섞이면, 세션 라벨 대신 **구간 라벨 파일**을 따로 둡니다. 핵심 지표인 일시 동작 오탐률을 계산하려면 이 파일이 필요합니다.

- 파일 이름: 같은 세션 이름 + `.labels.csv` (예: `P01_20261120_140102_9f3a1c2e_label0.labels.csv`)
- 센서 CSV는 절대 고치지 않습니다. 라벨 기준이 바뀌면 이 파일만 고칩니다.
- 구간 라벨 파일이 있으면 학습·평가는 파일명의 `label`보다 이 파일을 우선합니다.

위 내용은 **3차 실습용 제안**입니다. 현재 `python/ALIGN_live_demo`의 학습·평가 코드는 세션별 단일 라벨만 지원하며 `.labels.csv`를 읽어 적용하는 기능은 아직 없습니다. 이 버전을 사용할 때는 세션 원본 CSV만 있는 폴더를 지정하세요. 구간 라벨 지원을 구현하기 전에는 혼합 동작 세션을 이 데모로 평가하지 않습니다.

```
start_us,end_us,action
953404219,961204000,sitting_good
961204000,975000000,slouch
978500000,981200000,pick_up
```

| 열 | 설명 |
| --- | --- |
| `start_us`, `end_us` | 구간 시작·끝. 영상 시간이 아니라 센서 CSV의 `time_us`(ESP32 시계) 기준 |
| `action` | 아래 목록 중 하나. 목록에 없는 동작은 먼저 팀에서 추가를 정한 뒤 씁니다 |

| `action` | 종류 | 설명 | 알림 정답 |
| --- | --- | --- | --- |
| `sitting_good` | 지속 | 바른 자세로 앉음 | 울리면 안 됨 |
| `slouch` | 지속 불량 | 구부정하게 앉음 (30초 이상) | 울려야 함 |
| `turtle_neck` | 지속 불량 | 거북목 (30초 이상) | 울려야 함 |
| `pick_up` | 일시 동작 | 물건 줍기 | 울리면 안 됨 (오탐) |
| `tie_shoes` | 일시 동작 | 신발 끈 묶기 | 울리면 안 됨 (오탐) |
| `stretch` | 일시 동작 | 기지개 | 울리면 안 됨 (오탐) |
| `look_back` | 일시 동작 | 뒤돌아보기 | 울리면 안 됨 (오탐) |
| `transition` | 기타 | 동작 사이 전환, 애매한 구간 | 학습·평가에서 제외 |

규칙:

- 구간은 서로 겹치지 않게 적고, 라벨이 없는 시간은 학습·평가에서 제외합니다.
- **영상과 맞추기**: 기록을 시작하면 몸통을 3번 두드립니다. CSV에서 가속도 스파이크 3개의 `time_us`와 영상에서 두드린 시각을 짝지어 영상 시간을 `time_us`로 바꿉니다. 맞춘 오차는 0.5초 이내가 목표입니다.
- 라벨은 가능하면 촬영 당일, 영상을 보며 작성합니다.
- 1초 구간(50행)이 두 `action`에 걸치면 그 구간은 제외합니다.

## summary.json에서 볼 것

| 필드 | 정상 기준 |
| --- | --- |
| `received_hz` | 49 ~ 51 |
| `missing_slots` | 0 (순번 누락 수) |
| `malformed`, `read_fail_messages` | 0 (형식 오류 줄, 센서 읽기 실패) |
| `timing_anomalies` | 0 (샘플 간격이 20ms에서 5ms 넘게 벗어난 횟수) |
| `near_full_scale_rows` | 0 (가속도 1.98g 또는 자이로 247.5°/s 이상인 행, 포화 의심) |
| `warnings` | 빈 목록 |
| `reason` | `duration_complete` (끝까지 수집됨) |

경고가 있는 세션은 지우지 말고 그대로 두되, 학습에 쓸지 팀에서 판단합니다.

## 학습할 때 쓰는 단위

학습·실시간 판정 코드는 같은 세션 안의 **연속 50행(약 1초)**을 겹치지 않게 묶어 한 구간으로 씁니다. 누락·시간 이상·포화가 생기면 그 구간은 버리고 새로 모읍니다. 평가할 때는 같은 세션(나중에는 같은 사람)이 학습과 평가에 섞이지 않게 나눕니다.
