# ALIGN 실시간 0/1 판정 연습

현재 모델은 **손으로 센서를 기울여 만든 10세션**으로 학습했습니다. 실제 사람의 자세를 검증한 모델은 아닙니다. 나중에 몸에 착용해 수집한 CSV로 다시 학습하고 모델 파일을 바꿀 수 있습니다.

## 1. 처음 실행하기

1. ZIP을 압축 해제합니다. `live_predict.py`, `train_model.py`, `requirements.txt`가 보이는 폴더로 들어갑니다.
2. 탐색기 주소창에 `powershell`을 입력하고 Enter를 누릅니다.
3. Python 3.10 이상을 사용합니다. 같은 Python에 pyserial을 이미 설치했다면 설치 명령은 생략해도 됩니다.

```powershell
py -m pip install -r requirements.txt
py live_predict.py --port COM13
```

창이 열리면 모델 종류와 COM 포트를 확인한 뒤 **실시간 연결** 버튼을 누릅니다. 실제 포트가 COM13이 아니면 변경하세요.

다음부터는 같은 폴더의 `run_demo.cmd`를 더블클릭해도 됩니다. 현재 파일 위치를 자동으로 사용해 창을 열고 COM13을 미리 입력합니다. 실제 연결은 창에서 **실시간 연결**을 눌러 시작합니다.

- Arduino 시리얼 모니터·플로터와 `collect_csv.py`를 먼저 종료합니다. COM 포트를 동시에 열 수 없습니다.
- ESP32에는 기존 ALIGN v2/v3 로거가 업로드되어 있으면 됩니다. 다시 업로드할 필요가 없습니다.
- USB를 연결한 상태에서 사용합니다. 연결 후 약 3초 부팅을 기다리고 자동으로 수집 시작 명령을 보냅니다. `S`를 따로 입력하지 않습니다.
- 데이터가 약 1초 모이면 판정이 나타납니다. 이후 약 1초마다 갱신됩니다.
- 센서를 천천히 기울여 판정이 어떻게 바뀌는지 확인합니다. **중지** 버튼으로 종료하거나 창을 닫습니다.

현재 모델은 `models/hand/model.json`을 자동으로 불러옵니다. 화면의 0/1은 학습할 때 지정한 센서 상태를 뜻합니다. 새로운 동작에서도 정확히 구분된다는 보장은 없습니다.

포트 목록을 확인하려면 다음을 사용합니다.

```powershell
py live_predict.py --list-ports
```

## 2. 센서 없이 CSV 재생하기

프로그램 창에서 **CSV 재생**을 누르고 `../../data/hand_tilt_practice_01`의 CSV 하나를 선택합니다. 저장된 측정값이 시간 순서대로 들어와 판정 과정이 표시됩니다.

명령으로 파일을 지정할 수도 있습니다.

```powershell
py live_predict.py --replay "../../data/hand_tilt_practice_01/P01_20261113_152557_db3c0163_label1.csv"
```

함께 제공한 CSV는 현재 모델의 학습에 사용된 파일입니다. 재생은 프로그램 작동 확인용이며, 새로운 데이터에 대한 성능 평가가 아닙니다. 실제 COM 통신은 CSV 재생만으로 검증되지 않습니다.

## 3. 화면과 판정 기록

- **손 기울기 모델:** 상태 0 / 상태 1.
- **착용 데이터 모델:** 정상 0 / 불량 1. 사람이 부여한 라벨 기준을 모델이 학습한 결과입니다.
- 초기에는 데이터 수집 대기 상태가 표시됩니다. 누락·시간 간격 이상·포화가 생기면 현재 구간을 버리고 연속된 새 데이터가 모일 때까지 기다립니다.
- 신호가 끊기거나 포트 오류가 나면 상태와 오류 메시지를 확인하고 다시 연결합니다.

판정 기록은 프로그램 폴더의 `logs` 아래 CSV로 저장합니다. 모델 식별 정보, 모델 종류, 판정 및 두 라벨 중심까지의 거리를 기록합니다. **거리는 확률이나 신뢰도 퍼센트가 아닙니다.** 원시 12채널 데이터를 수집하려면 기존 `collect_csv.py`를 별도로 사용하세요.

PC 수신 버퍼가 4096바이트를 넘거나 보드 시간 대비 수신 지연이 2초를 넘으면 오래된 데이터로 계속 판정하지 않도록 중단합니다. 원인을 확인한 뒤 다시 연결하세요.

## 4. 지금 자료로 학습을 다시 실행하기

학습된 모델이 포함되어 있으므로 실시간 판정을 시작하는 데 재학습은 필요 없습니다. 학습 과정을 연습하려면 다음을 실행합니다.

```powershell
py train_model.py --data ../../data/hand_tilt_practice_01 --kind hand --split session --out models/hand_retrained
```

결과는 지정한 폴더의 `model.json`, `evaluation.json`에 저장됩니다. 프로그램에서 **모델 선택**으로 새 `model.json`을 고르거나 다음과 같이 실행하세요.

```powershell
py live_predict.py --port COM13 --model models/hand_retrained/model.json
```

기존 모델이 있으면 덮어쓰기를 막습니다. 결과를 보존하려면 새 출력 폴더를 사용하세요. 의도적으로 덮어쓰려면 학습 명령에 `--overwrite`를 추가합니다.

## 5. 나중에 실제 착용 데이터로 바꾸기

1. 센서 장착 위치와 축 방향, 정상/불량 라벨 기준을 정하고 기록합니다.
2. 기존 수집기로 별도 폴더(예: `D:\ALIGN_body_data`)에 저장합니다. 손 기울기 연습 자료와 섞지 않습니다.
3. 라벨 0과 1 각각 여러 독립 세션을 수집합니다. 세션 분할 학습에는 최소 라벨당 2세션이 필요하며, 최소 개수만으로 충분한 성능이 보장되지는 않습니다.
4. 다음 명령으로 새 모델을 만듭니다.

```powershell
py train_model.py --data "D:\ALIGN_body_data" --kind body --split session --out models/body
```

5. 새 모델로 실행합니다.

```powershell
py live_predict.py --port COM13 --model models/body/model.json
```

`--kind body`는 데이터 종류와 표시명을 기록합니다. 이 옵션만으로 실제 자세 검증이 완료되는 것은 아닙니다. 학습 폴더에 없는 새 세션에서도 확인하세요.

여러 사람에게 일반화되는지 확인하려면 수집 시 `--subject P01`, `P02`처럼 ID를 구분하고, 학습할 때 다음을 사용합니다.

```powershell
py train_model.py --data "D:\ALIGN_body_data" --kind body --split subject --out models/body_subject
```

피험자 분할은 최소 2명의 서로 다른 ID가 필요합니다. 한 사람을 평가용으로 제외한 나머지 학습 자료에도 두 라벨이 있어야 합니다. 새 사람에 대한 신뢰할 만한 평가는 더 많은 사람과 조건에서 확인해야 합니다.

## 6. 학습·평가 방식

- 입력은 기존 로거 CSV의 12채널입니다. 가속도는 g, 자이로는 deg/s이며 50Hz 기준입니다.
- 연속 50행의 채널별 평균 12개를 하나의 특징으로 씁니다. 구간은 겹치지 않으며 세션 경계를 넘지 않습니다. 끝에 남는 50행 미만은 사용하지 않습니다.
- 학습 자료의 평균·표준편차로 표준화하고 라벨별 중심을 계산합니다. 새 특징이 어느 중심에 가까운지로 0/1을 판정합니다.
- 세션 분할은 같은 세션이 학습과 평가에 섞이지 않도록 최대 5회 교차검증합니다. 피험자 분할은 한 사람씩 통째로 제외해 평가합니다.
- 표준화 통계는 각 회차의 학습 자료에서만 계산합니다. 시간·순번·세션 ID·피험자 ID·라벨은 입력 특징에 넣지 않습니다.
- 평가가 끝나면 사용할 최종 모델은 전체 유효 학습 구간으로 다시 만듭니다. 교차검증 결과와 최종 모델 학습 파일의 재생 결과는 서로 다른 의미입니다.
- 누락과 포화 부근의 구간은 이어 붙이지 않습니다. 학습 결과에서 사용된 구간 수와 제외 내역을 확인하세요.
- 이 버전은 확률 출력이나 다수결 보정을 하지 않습니다. 안정적으로 구분되지 않는 새로운 상태도 0/1 중 가까운 쪽으로 판정할 수 있습니다.

제공한 손 기울기 자료의 세션 분리 평가는 **100구간 중 87구간 정답(87%)**이었습니다. 이는 같은 수집 환경의 연습 자료에서 얻은 예비 결과입니다. 실제 인체 자세 분류 정확도로 해석하지 않습니다.

## 7. 새로운 기록으로 독립 테스트하기

새로 측정한 테스트 CSV는 학습 폴더와 별도로 보관합니다. 같은 라벨 0/1 기준을 사용하고, 다음 명령에서는 **재학습하지 않은 기존 모델**로 새 세션을 평가합니다.

```powershell
py evaluate_model.py --model models/hand/model.json --data "D:\ALIGN_hand_test" --out test_results/hand_01
```

실제 착용 모델이면 `--model models/body/model.json`과 해당 착용 테스트 폴더를 지정합니다. 학습 세션이나 같은 센서 기록의 복사본이 들어가면 중단합니다. `../../data/hand_tilt_practice_01`는 이미 학습한 자료라 이 명령의 새 테스트 입력으로 사용할 수 없습니다. 새로운 폴더에 생기는 `evaluation.json`과 `predictions.csv`를 확인하세요. 같은 사람이 새로 측정한 결과는 그 사람의 새 세션 평가이며, 새로운 사람에 대한 평가와 다릅니다.

## 8. 자주 생기는 문제

| 증상 | 확인할 내용 |
|---|---|
| `can't open file ...live_predict.py` | 현재 PowerShell 폴더에 해당 파일이 있는지 확인합니다. 압축 해제된 안쪽 폴더로 들어가세요. |
| `No module named 'serial'` | `py -m pip install -r requirements.txt`를 실행합니다. |
| COM 포트 열기 실패 / Access denied | Arduino 모니터·플로터·수집 프로그램을 닫고 포트 번호를 확인합니다. |
| 데이터 없음 / 헤더 불일치 | 기존 ALIGN v2/v3 스케치인지, 115200 baud·50Hz·12채널 형식인지 확인합니다. |
| 포화·누락으로 대기가 반복됨 | 센서와 USB 연결을 확인하고 급격한 움직임을 줄입니다. 측정 범위를 바꾸면 변환·검증·모델도 함께 바꿔야 합니다. |
| 모델 형식 오류 | 이 패키지의 `train_model.py`로 만든 `model.json`을 선택합니다. |
| Tkinter 관련 오류 | Tk/Tcl 구성 요소가 포함된 Windows Python을 사용합니다. |

PC가 절전 상태가 되지 않게 하고 실시간 수집 중에는 USB 연결을 유지하세요. 제작 환경에서 전처리, 재학습, 독립 평가, CSV 재생과 모의 직렬 통신을 검사했습니다. 실제 ESP32 연결과 사용자 PC에서의 창 표시는 아직 확인하지 못했습니다. 처음에는 CSV 재생으로 화면을 확인한 뒤 실제 COM 포트에 연결하세요.

## 포함한 P01 착용 기준선

`models/body/model.json`은 `data/body_P01`의 실제 착용 20세션으로 학습한 최근접 중심 분류기입니다. 5회 세션 분리 평가에서 293/400 구간 정답(73.25%), 불량 재현율 57.5%였습니다. 동일 P01의 세션 간 결과이며 다른 사람에 대한 정확도는 아닙니다.

`run_demo.cmd`의 기본값은 계속 손 기울기 모델입니다. 창에서 **모델 선택 → models/body/model.json**을 고르거나, 이 폴더에서 다음 명령으로 실행합니다.

```powershell
py live_predict.py --port COM13 --model models/body/model.json
```

학습기는 폴더와 ZIP에서 Excel `~$*.csv` 임시 파일을 제외하지만, 실제 원본 CSV의 열·숫자·세션 검사는 유지합니다.
